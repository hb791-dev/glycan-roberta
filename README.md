# glycan-roberta-project2

Clean rebuild of the glycan RoBERTa workflow.

This repository is intended to become the colleague-facing, reproducible version
of the project. The original `glycan-roberta-project` and
`MyDrive/ProjectRoot` remain untouched as legacy records.

Planned workflow:

1. Explore the raw dataset.
2. Generate train, validation, and test splits.
3. Build tokenizers.
4. Preprocess datasets for each tokenizer.
5. Train masked language models.
6. Review validation diagnostics.
7. Evaluate the saved best model on test.

Drive root for the rebuilt workflow:

- `MyDrive/ProjectRoot2/`

This repo is currently a skeleton and will be filled in incrementally.
